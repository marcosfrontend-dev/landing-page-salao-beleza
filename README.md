# ✨ AC Studio — Beleza & Estética Avançada

Uma landing page responsiva e elegante desenvolvida em *Dark Theme* com paleta Bronze e Dourado Nude, focada na conversão e agendamento de procedimentos estéticos via WhatsApp.



---

## 🚀 Funcionalidades

- **Design Responsivo & Elegante:** Visual sofisticado focado em estética premium, utilizando tipografia serifada (`Cormorant Garamond`) e paleta inspirada no branding oficial.
- **Tabela de Procedimentos:** Exibição clara de serviços (Design de Sobrancelhas, Lash Lifting, Limpeza de Pele) com destaque para o serviço mais desejado.
- **Modal de Agendamento Interativo:** Captura de dados (nome, procedimento, data e horário) com trava automática para impedir seleção de datas retroativas no calendário.
- **Integração Nativa com WhatsApp:** Formatação de texto automatizada com `encodeURIComponent` enviando o pedido pré-formatado diretamente para o atendimento do Studio.
- **Navegação Mobile:** Menu hambúrguer otimizado para dispositivos móveis e rolagem suave (*smooth scroll*) entre as seções.

---

## 🛠️ Tecnologias Utilizadas

Projeto desenvolvido com tecnologias nativas do front-end, garantindo alta performance e carregamento veloz:

- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Layout moderno utilizando Flexbox, CSS Grid, Variáveis CSS e gradientes customizados.
- **JavaScript (ES6+):** Manipulação dinâmica do DOM, tratamento de datas/horários e disparo para a API `wa.me`.
